Однократная настройка на сервере

Для обновления без PowerShell требуется отдельная задача Windows с повышенными правами. Она продолжит работу, когда веб-портал перезапустится.

Запустите PowerShell от имени администратора под той же учётной записью, что и остальные задачи ETL Dev:

cd "C:\Users\ETLadmin\Desktop\TransferData"
.\windows\Install-PortalUpdater.ps1

Установщик один раз запросит пароль этой Windows-учётной записи. Пароль сохраняет планировщик Windows; в браузер и конфигурационные файлы портала он не передаётся. Затем обновите эту страницу.
