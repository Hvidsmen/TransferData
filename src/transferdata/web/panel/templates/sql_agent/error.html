Не удалось прочитать задания SQL Server Agent.

Проверьте доступность сервера, TLS и права учётной записи веб-портала на чтение метаданных заданий в msdb. Доступа только к DataWH недостаточно. Сведения других подключений не подставляются.

Какие сведения нужны администратору SQL Server

Портал читает sysjobs, syscategories, sysjobhistory, sysjobactivity, syssessions, sysjobschedules, sysschedules и sysjobsteps в msdb. Нужны права просмотра этих сведений. Права sysadmin для портала не требуются.
