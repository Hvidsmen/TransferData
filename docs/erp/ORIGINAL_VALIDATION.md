# Проверки в облачной среде

Проверено 15 октября 2026 г., Python 3.12.14, Debian 13 x86_64.

- `python -m pytest -q`: **67 passed, 1 skipped**. Пропущен только opt-in MS SQL integration: реальные SQL Server/реквизиты не предоставлены.
- `manage.py check`: ошибок нет.
- `manage.py makemigrations --check --dry-run`: расхождений моделей и миграций нет.
- `manage.py migrate --noinput`: миграции применены; повторный запуск не меняет схему.
- `manage.py collectstatic --noinput`: выполнено.
- `python -m pip check`: конфликтов зависимостей нет.
- HTTP: страница входа 200, локальный HTMX 200, Dashboard без авторизации 302 на вход. Авторизованные страницы, формы, очередь и HTMX-фрагменты проверены Django test client.
- Worker запущен в отдельном процессе. Повторный worker отклонён OS lock. Команда планировщика запускается, пустая служебная БД не создаёт искусственных заданий/показателей.
- Microsoft ODBC Driver 18 зарегистрирован и загружается. Пакет установлен без root, с проверкой GPG-подписи Microsoft Release.gpg и цепочки SHA256 Release → Packages.gz → deb. Повторная установка успешна. Проба на закрытом локальном порту вернула HYT00, а не ошибку загрузки драйвера. Это **не проверка соединения с настоящим SQL Server**.
- Сохранены cloud `install_script` и `start_skill`; install script выполнен повторно успешно. Публикация конфигурации и восстановление в новой задаче не выполнялись.

## Не проверено и ограничения

Реальный перенос MS SQL → MS SQL, TLS/права ваших серверов, Windows Authentication под service account, Windows Task Scheduler и Waitress/IIS на Windows требуют приёмочной проверки на вашей инфраструктуре. Интеграционный тест готов к запуску в отдельной тестовой базе; mock-тесты не доказывают поведение настоящего сервера.

MVP использует один локальный worker/один сервер/локальную SQLite. Incremental отключён. Полные инструкции, ограничения типов, транзакций и порядок действий после аварии находятся в README.md. Создайте администратора через `manage.py createsuperuser`: учётные записи с придуманными паролями не создавались.
